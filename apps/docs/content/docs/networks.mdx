Kakure runs on two Zcash networks and keeps them apart on your device: each has its own operator key, chips,
positions and cached files, and a backup from one can't be imported into the other.

| | Testnet | Mainnet |
| --- | --- | --- |
| Coin | TAZ, which has no value | ZEC |
| Status | Live | Its key is built in; trading opens when the operator publishes it |
| Deposit confirmations | 2 | 3 |
| Stake per trade | 0.001 to 1 | 0.001 to 0.05 |
| Switching to it | One tap | A deliberate "Slide to use real money" |

Switch with the network capsule at the top of the app; the whole app re-tints so you always know which one you're
on. Every visit loads both networks' signed files, whichever you use, so browsing doesn't tell the site which one
you're on; a trade does, since its relay path names the network.

## Getting TAZ

Testnet coins are free from a faucet:

- [Fauzec](https://fauzec.com/) sends to Unified and Sapling addresses.
- [Valar](https://faucet.testnet.valargroup.dev) sends a small amount once a day.

Send them to your wallet's shielded address, then deposit TAZ exactly as you would ZEC.

## Links

A trade link names only the asset and Window length, after the `#` (`/trade#BTC/5m`), so the site never receives
it. It opens on whichever network you're on.
