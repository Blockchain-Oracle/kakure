## A trade, end to end

```mermaid
sequenceDiagram
  participant You as Your browser
  participant Site as Site and relay<br/>(one Cloudflare worker)
  participant Op as Operator<br/>(gateway and mint)
  participant Prices as Price relay
  You->>Site: GET latest.json and bundle<br/>(both networks, every minute)
  You->>Prices: Price stream<br/>(every symbol)
  Note over You: Quote from the public formula<br/>on the live price
  You->>Site: POST /ohttp/testnet<br/>sealed: chips, Window, side, max ask
  Site->>Op: A fresh request: only the sealed bytes
  Note over Op: Check the chips unspent,<br/>quote, sign a certificate
  Op-->>Site: Sealed answer: certificate and change
  Site-->>You: Sealed answer
  Note over You: Check signatures and DLEQ proofs,<br/>save in the encrypted vault
  Note over Op: After the close: 2 of 3 exchanges' prints
  You->>Site: POST /ohttp (sealed): redeem
  Site->>Op: Sealed bytes
  Op-->>You: Fresh blind-signed chips (via the relay)
```

## The operator's minute

```mermaid
flowchart LR
  sync[Chain sync over Tor, every 15 s] --> deposits[Deposits: memo id, confirmations]
  deposits --> mint[Mint: blind signatures, spent set]
  stream[Price relay stream] --> quotes[Quotes and the exit watcher]
  venues[Exchanges' 1-minute candles] --> minute[Minute tick, 7 s past the minute]
  minute --> settle[Lines, settlements, σ]
  settle --> publish[Signed bundle every minute,<br/>prints file every hour]
  publish --> host[(The site's storage)]
  mint --> payouts[Withdrawals: 1-2-5 notes at random times]
  payouts --> tor[Broadcast over Tor]
```

## Data flow

```mermaid
flowchart TB
  subgraph device[Your device]
    app[Web app]
    vault[(Encrypted vault: chips and positions)]
    sw[Offline cache]
  end
  worker[Site and relay: static files, signed data, /ohttp, /arcade; logs off]
  arcade[Arcade service: nicknames, seeds, replayed runs]
  prices[Price relay: every symbol to everyone]
  op[Operator gateway and mint]
  ex[Coinbase, Kraken, Bitstamp, Gemini]
  op -- pushes signed files --> worker
  app -- same files for every visitor --> worker
  app -- sealed requests --> worker
  worker -- sealed bytes only --> op
  app -- arcade calls --> worker
  worker -- method, path and body only --> arcade
  arcade -- reads signed prints --> worker
  app -- one price stream per tab --> prices
  prices --> ex
  op --> ex
  app --- vault
  app --- sw
```

The app never connects to the operator directly: every request is sealed to the operator's published key and goes
through the relay, which forwards only the sealed bytes.

## Who sees what

```mermaid
flowchart LR
  trade((Your trade)) -->|"Window, side, stake, time"| op[Operator]
  trade -->|"your IP and the network, sealed bytes only"| relay[Site and relay]
  deposit((Your deposit)) -->|"a shielded transaction, nothing else"| chain[Chain observers]
  deposit -->|"its amount"| op
  wallet((Your wallet)) -->|"your IP, sync and send times, unless you use Tor"| server[Your wallet's server]
  visit((Your visit)) -->|"IP, while prices show; the chart's candle interval"| prices[Price relay]
  play((Your arcade runs)) -->|"nickname, scores, the day; never your IP"| arcade[Arcade service]
  op -->|"prices, outcomes, the house's book hourly, volume in groups of 3"| public[Everyone]
```
