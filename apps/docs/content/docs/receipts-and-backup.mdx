## Where your tickets live

Only on your device. The web app keeps them in your browser's IndexedDB, encrypted with AES-GCM under a key the
browser won't let any code read out, with a separate key and store per network. Each record has a random id, so
nothing stored, not even a record's name, can be matched to the published ticket lists. There's no account and no server
copy: if you clear this browser's data without an export, the tickets are gone (payouts still go to the addresses
in your bets).

## Receipts

Open a ticket in the portfolio to see it as a perforated slip. Receipts are made on your device from your ticket and
the signed bundle, and they're **redacted by default**: no payout address, no transaction id, no bet time.

- **Outcome slip:** the market, side, size and result. It carries nothing derived from your ticket hash, not even a
  ticket number, so it can't be matched to the signed list or traced to your payment.
- **Provable:** adds your ticket's nonce, so anyone with the link can recompute the ticket hash and find it in the
  signed list; only this mode prints a ticket number (the start of the hash). Share it only with someone you want
  to prove the bet to. A copied Provable link is wiped from your clipboard after a minute where the browser allows it.

Each receipt can be saved as a PNG, emailed (your mail app opens with a short summary; attach the PNG), or shared
as a `/verify#…` link.

## Export and import

**Settings → Backup.** Enter a passphrase of at least 8 characters, then **Export**: you get a `.kakure` file with
this network's tickets, encrypted with AES-GCM-256 under a key derived from your passphrase (PBKDF2-SHA-256,
310,000 iterations). It includes payout addresses and nonces, so keep it like a wallet backup. **Import** takes the
same file and passphrase on another device. A file from the other network is refused: switch networks first.

## Lock with a passphrase

The ticket store is encrypted either way, but by default its key sits next to it in this browser: any page script
on Kakure's origin can use it, though none can read it out. **Settings → Ticket lock** adds a passphrase (at least 8
characters). Every ticket is then re-encrypted under new keys that are stored only wrapped by your passphrase
(PBKDF2-SHA-256, 310,000 iterations), so someone with this browser's files sees only ciphertext. Enter the
passphrase once per tab to see or add tickets; it locks again when the tab closes, or with **Lock now**. You can
change the passphrase or turn the lock off while unlocked. If you forget it, only an exported file brings the
tickets back.

## What else is stored

Only preferences (network, theme, sound, motion) and a cache of the public signed files, the same ones every visitor
downloads, are kept outside the encrypted store. No ticket hash, nonce or result is ever written there.

## Forget this device

**Settings → Forget this device** erases everything Kakure stored in this browser: the ticket store, its keys and its lock,
settings, the cached public files and the service worker. It asks you to slide to confirm. Export first if you want
to keep your tickets.
